沿水岸牧马 (Riverside Eight Horses) — v1.0.0 正式版

郎世宁《郊原牧马图》（八骏图）WebGPU / Three.js 三维数字化交互复原与学术考据系统

快速上手：
1. 安装依赖：npm install
2. 本地调试：npm run dev
3. 生产构建：npm run build
4. 本地预览：npm run preview
5. 执行测试：npm test (18 项测试全数通过)

主要功能页面：
- 主场景入口：http://127.0.0.1:5173/ (index.html)
  * 全卷全景、清流近看、左侧马群、柳下灰马、柳冠近看、牧者花马等 6 大机位
  * 四季动态演进 (春、夏、秋、冬及冬落叶)
  * 十二时辰自然光照循环 (子丑寅卯辰巳午未申酉戌亥)
  * “画中有意” 深度学术考据与随卷读画面板
  * 原画 6882x2160 超清镜像对照模式
  * 沿岸慢行与步态微动控制
- 单件资产检视：/asset-review.html
- 骨骼动作检视：/motion-review.html
- 美术策划与历史记录：/design/pasture/
