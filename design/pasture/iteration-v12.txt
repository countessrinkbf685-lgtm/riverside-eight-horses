沿水岸牧马 · 第十二轮 / 文化融入

依据：根目录《郊原牧马图_考据研究.md》。原稿保留，网页可查阅原文副本。

体验
1. 顶部“画中有意”：八骏、牧者、水岸、红叶、海西笔意五段随卷导览。
2. 章节联动场景镜头；可近看灰斑马、牧者，回到秋景，或打开原画对照。
3. 点击八匹马，先阅读对应毛色与文化说明，制作/动作资料可展开查看。
4. 牧者以“圉人”这一通称介绍，保留姓名、职属与族属的不确定性。
5. 原文研究出处可展开；无 WebGPU 环境仍可阅读全部章节。

场景
左坡和柳根共 22 丛掌裂叶灌木，两区各 11 丛；调整叶片大小、仰角和疏密。
修正原红叶采样范围与岩石避让重叠的问题，避免全挤到柳根。
春夏绿叶、秋季朱红、冬季整叶退去；增加“坡石红叶”导览镜头。
既有八马、牧者绑定与行走保持原角色编号和动作分配。

考据处理
研究表格从右向左编号，运行时从左向右编号：H01 对研究 H08，依次对应，H08 对研究 H01。
“赤骥”“盗骊”等作为典故，不冠为本卷马匹的正式姓名。
南苑、永定河流域、上驷院与植物种类分别注明线索或演绎性质。
研究稿未提供可逐条核对的原始著录页码，本轮没有把推论提升为定论。
未在画面伪造题诗、作者署款或内府印章。

验证

npm run check:browser：原有场景和角色交互回归。
