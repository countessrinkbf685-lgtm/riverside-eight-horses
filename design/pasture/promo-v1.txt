沿水岸牧马 · 宣传片镜头设计 v1

规格：横版 1920×1080，24 fps，48 秒，H.264 MP4，立体声 AAC。
画面：当前 WebGPU 场景实际逐帧录制，隐藏交互界面，保留动态植被、水体及九位角色动画。
叙事：从画卷全景进入马群与牧者，再沿水、树、四季和昼夜回到完整画境。

00–06 秒｜水岸初醒
春日晨光，横向微移并缓推。建立八马、柳树、缓弯水岸与远山关系。
片名“沿水岸牧马”；副题“郎世宁《郊原牧马图卷》意境再现”。

06–12 秒｜八骏闲游
左侧马群中景，向右轻移，展示屈肢、采食与抬首之间的不同姿态。
字幕“俯仰之间，自有生意”。

12–18 秒｜柳影低回
柳下灰马中近景，轻推入，保留垂枝与清流的前后层次。
字幕“垂枝拂岸，灰马悠然”。

18–24 秒｜牧者相伴
牧者与花马双主体镜头，缓慢横移，保留衣袖和马身的完整轮廓。
字幕“人马相安，水草之间”。

24–30 秒｜清流有声
俯看水带，沿流向轻移，展示可见河床、波纹与白沫。
字幕“沿永定河意象，溯一带清光”；水声略抬高。

30–36 秒｜秋色入卷
柳冠与远山中景，缓拉开，展示秋色垂梢与岩质山脊。
字幕“柳梢与远山，相映成画”。

36–42 秒｜四时递嬗
固定全卷构图，平滑呈现春、夏、秋、冬，避免换季和运镜同时抢夺注意力。
字幕“春生 · 夏长 · 秋染 · 冬藏”。

42–48 秒｜昼夜流转
全卷缓拉远，从申时到子时。以冷色月夜收束，片名与结语渐隐。
结语“一卷水岸，十二时辰”。

声音：原创程序合成五声音阶拨弦、风与流水氛围；未使用商业曲库、他人录音或旁白。
视觉使用当前场景资产，现有模型细节属于本版本录制内容；此片不代表其他马尾已完成 H06 同级重制。
光照、季节与河水均为美术表达，非具体日期天文或水动力复原。

可复现：
node scripts/record-promo.mjs --preview  生成八镜头预览
node scripts/record-promo.mjs            逐帧录制无声画面母版
python scripts/promo-soundtrack.py       生成原创合成声轨
node scripts/finish-promo.mjs            混音、封装、完整解码验证并抽取成片分镜
输出目录：artifacts/promo-v1
